# Smart Waste Collection & Route Optimization Dashboard Using Power BI

## 📌 Project Overview

The Smart Waste Collection & Route Optimization project focuses on analyzing waste collection data using Microsoft Power BI. The project aims to help cities monitor waste collection performance, compare waste collected across zones, analyze fuel consumption and collection costs, and identify opportunities to improve waste management operations.

The dashboard transforms waste collection data into meaningful insights through interactive visualizations, KPIs, and data analysis.

## 🎯 Project Objectives

- Analyze the total waste collected across cities and zones.
- Monitor waste collection performance by waste type.
- Compare expected waste with actual waste collected.
- Analyze fuel consumption and collection costs.
- Identify high-performing cities and zones.
- Support better planning and cost-effective waste collection.

## 📊 Key Analysis

### 1. Waste Collection Analysis

Analyze the total quantity of waste collected to understand waste management performance across different cities and zones.

### 2. City-Wise Analysis

Compare waste collection across cities to identify areas with higher and lower collection volumes.

### 3. Zone-Wise Analysis

Evaluate waste collection performance across zones and identify differences in collection activity.

### 4. Waste Type Analysis

Analyze the amount of waste collected by waste type to understand the composition of collected waste.

### 5. Collection Efficiency Analysis

Compare actual waste collected with expected waste to evaluate collection efficiency.

### 6. Fuel Consumption and Cost Analysis

Analyze fuel consumption and fuel costs to understand operational expenses and identify opportunities to reduce collection costs.

## 📈 Power BI Dashboard

The dashboard presents key performance indicators and interactive visualizations to provide an overview of waste collection operations.

**Key Performance Indicators (KPIs):**
- Total Waste Collected (KG)
- Total Cities
- Total Bins
- Collection Efficiency (%)
- Total Collection Cost

**Visualizations:**
- City-Wise Waste Collection
- Zone-Wise Waste Collection
- Waste Type Distribution
- Expected vs. Actual Waste Collection
- Fuel Consumption Analysis
- Collection Cost Analysis
- Date-Wise Waste Collection Trends

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Microsoft Excel
- Power Query for Data Cleaning and Transformation
- DAX for Measures and KPI Calculations
- Data Modeling
- Interactive Data Visualization

## 💡 Key Insights

- Compared waste collection performance across cities and zones.
- Identified waste types contributing to the total collected waste.
- Evaluated collection efficiency by comparing expected and actual waste.
- Analyzed fuel consumption and collection costs.
- Used interactive filters to explore waste collection patterns by date, city, zone, and waste type.
